# Articles

This directory contains optional launch, education, and explainer drafts for AI Development Control Log.

They are not required to run the protocol, validator, templates, or daily digest automation.

Use them as examples for explaining the problem this project addresses:

- AI agents making product decisions without explicit user approval
- founders/operators needing readable evidence instead of black-box progress claims
- separating implementation work from governance, risk, verification, and rollback

If you fork this repository as a starter kit, you can safely delete this directory without affecting the scripts or templates.
